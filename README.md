# WorldWideGames

WorldWideGames is an Architect Industries browser-gaming platform focused on instant-play original games, broad genre variety, responsive desktop/mobile play, local progression, and increasingly ambitious campaign releases.

## Current verified candidate

**v58 — Quiet Protocol 2.0: Ghostline**

Quiet Protocol now spans three stealth facilities with wall-occluded patrol/camera vision, investigation AI, noisy sprinting, relay hacking, rechargeable cloak energy, limited pulse jammers, persistent mission unlocks and records, touch/gamepad/remapped controls, and clean-extraction telemetry. The verified v57 Glasswing Polo 2.0 Grand Circuit remains intact.

## Run locally

Serve the repository over a local HTTP server and open `index.html`, for example:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000/`.

See `PROJECT_STATE.md`, `TEST_REPORT.md`, `RELEASE_NOTES.md`, and `THIRD_PARTY_NOTICES.md` for current details.
