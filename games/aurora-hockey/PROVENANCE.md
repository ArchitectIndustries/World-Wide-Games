# Aurora Hockey provenance

Aurora Hockey is an original WorldWideGames game created for Architect Industries.

- **Code:** The Canvas2D renderer, fixed-step collision simulation, bounded opponent logic, input handling, UI, and persistence were written specifically for this game.
- **Art:** The rink, strikers, puck, interface, particles, and `covers/aurora-hockey.svg` are original procedural/vector artwork. The interface uses system fonts.
- **Audio:** Sound effects are original WebAudio sine-wave envelopes generated locally. No music recordings or sampled sound effects are included.
- **Design reference:** EXIT13's publicly served catalog identified air hockey as a useful genre reference. Aurora Hockey uses the conventional rules of air hockey and independently created names, presentation, implementation, and difficulty tuning.
- **No EXIT13 imports:** No EXIT13 source files, code excerpts, images, posters, logos, audio, models, or other assets are included in the game or its cover. Public reference bundles inspected during research were kept outside the deliverable.
- **Dependencies:** None. The game uses native browser Canvas2D and WebAudio APIs.

This record describes asset and implementation provenance; it does not grant rights to unrelated reference material.
