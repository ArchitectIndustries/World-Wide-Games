Stages

Keyboard: F/L/R/P queue a command, Enter starts or resumes automatic Run, S executes one Step, K pauses an automatic run, Backspace removes. Focus buttons and use Enter or Space to activate them normally. Pause to inspect the highlighted instruction, Step to advance safely, or Run to resume. Escape cancels and resets the current stage. Core credits are banked only after the gate; changing maps forfeits pending credit. The cyan dashed line forecasts only the current queued program; the real drone does not move until Run or Step. Red crosses predict blocked moves. A queued program is charged once when started, whether stepped, run, or canceled; pause/resume never charges again. The ranked clock starts on your first execution and counts only foreground play. Switching tabs pauses automatic execution; return and press Run or Step to continue without losing a command.
