# WorldWideGames Release Notes

## v45 — Vector Shatter

WorldWideGames v45 adds **Vector Shatter 1.0**, an original five-sector brick-breaker campaign from Architect Industries. The game combines angle-controlled rebounds, normal and armored panels, prism panels, combo scoring, multiball, three recovery lives, and five power systems: Wide, Multi, Slow, Guard, and Pierce.

Vector Shatter supports permanent Arrow/A-D movement aliases alongside saved custom remaps, pointer and touch controls, and gamepad input. Local records track best score, campaign clears, furthest sector, and collected powerups.

Platform integration adds a new **Brick Breaker** entry to Classics, Reimagined, makes Vector Shatter the featured release and first PWA shortcut, adds **Shatter Crown** and **Prism Harvester** achievements, and advances the offline cache to `wwg-v45`.

Release verification is green at **75 games / 122 genre tags / 120 achievements / 48 remappable releases**, with 75/75 runtime-clean catalog coverage, 75/75 boot coverage, 75/75 objective/control pages, 48/48 remappable profiles, and 157/157 local-origin paths.
